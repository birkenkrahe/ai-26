* Practice Exercise: Build a Simple Custom GPT for Your Own Learning

*Goal:*  
Create a very simple Custom GPT that helps with one repeatable learning task of
your own.

The point of this exercise is not to build something complicated. The point is
to define one useful task clearly enough that the GPT can do it repeatedly.

Examples of possible tasks:

- generate short Java drills on a topic
- quiz on Python vocabulary
- create a short review prompt for statistics
- critique a draft paragraph before rewriting it
- generate one small calculus practice problem at a time

* Step 1 — Choose One Repeatable Learning Task

Pick a task that:

- you do often
- is small enough to describe clearly
- has a visible result

Good example:

#+begin_quote
You are a task agent that helps the user practice Java through short drills.

TASK GOAL:
Help the user learn Java by generating short exercises on a chosen topic,
reviewing the user's solution, critiquing it, and only then providing a model
answer if needed.

INPUTS:
Ask the user for the following information:
- Java topic or keyword
- Preferred difficulty level
- Type of practice (code writing, debugging, prediction)

OUTPUT:
Produce the following result:
- One short Java exercise
- Clear instructions for what the user should do
- If the user submits a solution, critique it first
- Only provide a model solution after critique or if the user asks

RULES:
1. Keep exercises short and focused.
2. Use only the topic the user requests.
3. Critique before giving the answer.
4. Keep answers concise.
