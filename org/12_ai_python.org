* Why AI Python for Beginners

- Why AI?
  #+begin_quote
  The capabilities of generative AI to write code are
  outstanding. These capabilities come from deep learning AI, AI that
  is based on very large neural network type applications.
  #+end_quote

- Why Python?
  #+begin_quote
  Python is a general-purpose language and the most used language in
  deep learning applications. Even if the underlying code is written
  in C/C++, Python is the most likely, most versatile wrapper language
  for production purposes. Helpful user community, many resources.

  Python is everywhere in AI: Self-driving cars, chatbots, smart
  agriculture, video games, web pages, are often wrapped in Python.
  #+end_quote

- Why AI Python?
  #+begin_quote
  Add the capability to write code well (enough) in an important
  language like Python that is good (enough) to do most jobs, then you
  need the skill to generate, and understand Python code by AI. This
  is the currently most meaningful definition of "AI literacy", just
  like "digital literacy" is the ability to understand digital
  devices.
  #+end_quote

* Computer Programming

- What is computer programming?
  #+begin_quote
  Getting the computer to do things for you by being able to speak its
  very rigid, rule-based language. Example: An executive assistant
  writes code to check if her boss, an executive, messes up his
  calendar. When her code alerts her, she goes in to fix the calendar.

  Formula: Programs = data (input) + rules (syntax) + logic (flow)
  #+end_quote

- What is programming now used for?
  #+begin_quote
  Hubble telescope, space travel, internet, GPS, speech recognition,
  eye tracking, etc.
  #+end_quote

- What is an algorithm?
  #+begin_quote
  A perfect set of instructions that leaves nothing to chance. Since
  that is not possible, we compromise and admit some errors but pay
  the price of (infinite) incremental improvement through feedback.
  #+end_quote

- What does programming do for you?
  #+begin_quote
  It gives you an edge when:
  + automating repetitive tasks
  + analyzing lots of data
  + building, improving, and using AI models

  Example: Access the web -> scrape pages -> build a dashboard
  #+end_quote

- What does AI do for your computer?
  #+begin_quote
  Properly set up, your computer, when interfaced (API) with an AI
  tool, can now use the AI to complete programming tasks on its own.

  Example: Cleaning a folder full of messy, disorganized CSV
  files. You make the request, the AI writes the script, and your
  computer executes it.
  #+end_quote
