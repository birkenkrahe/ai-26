* *Modify the production rules*

To improve the diagnostic model, add a new attribute:
*duration of symptoms*.

Use the following categories:
- *short* = fewer than 3 days
- *long* = 3 days or more

Use this attribute to refine each diagnosis as either:
- *acute* (short duration)
- *chronic* (long duration)

Original production rules:
#+begin_example
IF swollen glands = YES
THEN diagnosis = strep throat

IF swollen glands = NO AND fever = YES
THEN diagnosis = cold

IF swollen glands = NO AND fever = NO
THEN diagnosis = allergy
#+end_example

Your task:
Write a complete new set of production rules that incorporates the
*duration* attribute.

Requirements:
- Every original rule must be expanded to include duration
- Each final rule must include all relevant conditions
- Each diagnosis must be labeled as either *acute* or *chronic*

Hint:
Each original rule will split into two rules:
- one for short duration (acute)
- one for long duration (chronic)

Example (fully specified rule):
#+begin_example
IF swollen glands = YES AND duration = short
THEN diagnosis = acute strep throat
#+end_example

Now write all remaining rules in the same format.

** Solution

Updated production rules:
#+begin_quote
IF swollen glands = YES AND duration = short
THEN diagnosis = acute strep throat

IF swollen glands = YES AND duration = long
THEN diagnosis = chronic strep throat

IF swollen glands = NO AND fever = YES AND duration = short
THEN diagnosis = acute cold

IF swollen glands = NO AND fever = YES AND duration = long
THEN diagnosis = chronic cold

IF swollen glands = NO AND fever = NO AND duration = short
THEN diagnosis = acute allergy

IF swollen glands = NO AND fever = NO AND duration = long
THEN diagnosis = chronic allergy
#+end_quote

        │   └── Duration?
        │       ├── Short -> Acute cold
        │       └── Long  -> Chronic cold
        └── No
            └── Duration?
